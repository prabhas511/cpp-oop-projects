# C++ / OOP Portfolio

These three projects are intended as a learning portfolio.

## Resume-ready project descriptions (use only after understanding and testing)

### Student Management System
Built a console-based Student Management System in C++ using classes, constructors, encapsulation, vectors, functions, and search operations.

### Bank Account OOP System
Developed a C++ banking simulation demonstrating encapsulation, constructors, member functions, input validation, and console I/O.

### Library Management - Inheritance & Polymorphism
Implemented a C++ library-item hierarchy using inheritance, virtual functions, function overriding, base-class pointers, dynamic memory, and runtime polymorphism.

## Before putting these on a resume
1. Compile and run every project yourself.
2. Change/improve the projects based on your own understanding.
3. Be able to explain every important line and OOP concept.
4. Upload the source code and README files to your own GitHub repository.
5. Do not claim features that you did not implement.

Suggested GitHub repository name:
`cpp-oop-projects`
