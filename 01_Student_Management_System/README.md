# Student Management System

A console-based C++ project demonstrating object-oriented programming.

## Concepts demonstrated
- Classes and objects
- Encapsulation
- Constructors
- Private data members and public member functions
- Vectors
- References
- Functions
- Formatted console I/O
- Searching and basic problem solving

## Features
1. Add a student
2. Display all students
3. Search by roll number
4. Calculate a grade from marks

## How to run
Compile with a C++ compiler supporting C++11 or later:
`g++ main.cpp -std=c++11 -o student_manager`
Then run:
`./student_manager`

## Important
Understand every class, function and statement before presenting this project as your own work.
