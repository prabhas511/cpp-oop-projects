# Bank Account OOP System

A small C++ console project focused on encapsulation and class design.

## Concepts demonstrated
- Classes and objects
- Encapsulation
- Private data members
- Constructors
- Member functions
- References
- Conditional statements
- Input/output streams
- Validation and exception-like error handling through checks

## Features
- Create an account
- Deposit money
- Withdraw money with balance validation
- Display account information

## How to run
`g++ main.cpp -std=c++11 -o bank_account`
`./bank_account`

## Extension ideas
- Add multiple accounts using a vector
- Add transaction history
- Create SavingsAccount and CurrentAccount derived classes
